# KaroAI — ActionFlow

KaroAI turns real-world tasks into verified, actionable workflows.

## MVP
- Task intake
- Document understanding
- Requirements and gap detection
- Evidence-backed verification
- Draft generation
- Action checklist and progress
- Multi-agent activity timeline

## Architecture
Intake → Document → Requirement → Gap → Verification → Draft → Workflow

Built as a hackathon MVP with an extensible agent workflow architecture.
